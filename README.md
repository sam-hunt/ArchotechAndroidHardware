# Archotech Android Hardware

![RimWorld 1.6](https://img.shields.io/badge/RimWorld-1.6-blue)
![Version 1.0.0](https://img.shields.io/badge/version-1.0.0-green)

A RimWorld mod that adds a permanent, unlimited-power reactor for androids from [Vanilla Races Expanded - Android](https://steamcommunity.com/sharedfiles/filedetails/?id=2975771801).

## About

The vanometric reactor is built around an archotech vanometric power cell — the same technology that generates free energy forever in the base game. Miniaturized and adapted for android power systems, it eliminates the android's power need entirely. No more watching your best colonist shut down mid-surgery because their reactor drained.

## Features

- **Craftable** at the Android Part Workbench (requires Androidtech research)
- **Ingredients:** 20 Plasteel, 3 Advanced components, 1 Vanometric power cell
- **Installs** via surgery into the reactor slot, replacing the standard reactor
- **Removes the power need** — your android never needs a reactor replacement again
- **Recoverable** — surgically removing the reactor returns the item

## Requirements

- RimWorld 1.6
- Biotech DLC
- [Vanilla Races Expanded - Android](https://steamcommunity.com/sharedfiles/filedetails/?id=2975771801)

## Installation

**Steam Workshop:** Subscribe to the mod (link TBD)

**Manual:** Download the latest release and extract to your RimWorld `Mods/` folder.

## Compatibility

- Safe to add to existing saves
- Safe to remove (surgically remove the reactor first to avoid orphaned hediffs)
- Compatible with other VREA addons
